## 🧭 Sebelum Mengajukan Pertanyaan

1. Pastikan dependensi terpenuhi: PHP ^8.3, Composer, MySQL 8.0+, Node.js + NPM.
2. Local saja — `php artisan migrate:fresh --seed` untuk data awal yang bersih (JANGAN di production; production pakai `php artisan migrate --force`).
3. Jalankan `npm run build` bila aset Tailwind/Vite tidak muncul, dan cek `storage/logs/laravel.log` bila terjadi error 500.
4. Sertakan tangkapan layar, pesan error, dan langkah reproduksi saat bertanya.
